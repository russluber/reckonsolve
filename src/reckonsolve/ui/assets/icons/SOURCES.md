# Selected Lucide icons

These SVG files are unmodified selections from Lucide release `1.33.0`,
published at <https://github.com/lucide-icons/lucide/releases/tag/1.33.0>.
They are vendored so Reckonsolve remains fully functional offline and does not
ship the complete icon catalog. The release license is preserved in
`LUCIDE_LICENSE.txt`.
