# v0.6 visual verification

This is the human release-candidate record for the presentation work that automated tests cannot judge. It uses temporary databases only: closing a review window permanently removes that profile, and neither the stable nor development database is opened.

## Safe review profiles

Run one profile at a time from the repository root:

```powershell
uv run python tools/run_visual_review.py empty
uv run python tools/run_visual_review.py representative
uv run python tools/run_visual_review.py long-text
```

`empty` exercises first-run and empty states. `representative` supplies Open, Resolved, Invalid, Binary, and Numeric examples. `long-text` supplies the same states with deliberately long Questions, metadata, reasoning, terminal text, and Postmortems. All three use the visible **Reckonsolve Dev** identity but an injected temporary database and temporary `presentation.ini`.

## What counts as a pass

At each applicable matrix point:

- all essential text and controls are legible and reachable;
- labels wrap rather than overlap or silently disappear;
- scrollbars appear only where content genuinely cannot fit;
- expanded and compact navigation expose the same destinations, tooltips, and selection meaning;
- focus remains visible, disabled controls remain distinguishable, and no meaning relies on color or hover alone;
- plots retain readable axes plus their complete nonvisual table/summary; and
- success, retained error, and confirmation feedback remain inside the window without moving the active page.
