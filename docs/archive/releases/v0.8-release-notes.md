# Reckonsolve v0.8.0 — source release notes

> Archived release-note draft. Retained for history, not current setup or release status. Use the [changelog](../../../CHANGELOG.md) and [documentation index](../../README.md) for current guidance.

Status: source candidate; M57–M60 are manually accepted. Release closure
remains. A release tag and GitHub publication remain separate user steps.

## One-Shot Predictions

Record a final Yes probability or five Numeric quantiles before checking an answer
that already exists—for example, estimate a tree's height, then measure it. You can
copy a phone note into Reckonsolve later, save the forecast and answer together, or
save first and add the answer afterward. Optional reported times remain documentary;
the app separately records when you entered each fact.

New Prediction still defaults to **Adaptive**. Its top-right **One-Shot** button
opens the tailored form. One-Shot Detail has **Waiting for answer / Add answer**, Journal
history, Background, tags, and Postmortems. **Correct transcription** preserves the
original and every correction. Scores appear only after saving. One-Shots have no
ordinary forecast revisions, Reviews, Deadline, or time-weighted scoring.

Adaptive replaces the former With Deadline label. Its Binary and Numeric forecasts
can be revised or reviewed until their permanent Forecast Deadline; scoring is unchanged.
The One-Shot form's top-right **Adaptive** action returns to regular creation. Predictions
and Analytics use the same mode name, and existing Saved View filters retain their meaning.

CLI equivalents are `rscd create binary --one-shot`, `rscd create numeric --one-shot`,
and `rscd resolve ID`. `list --mode one-shot`, search, and Saved Views support mode
filtering; `show ID` includes original and corrected history. Use the matching stable
commands for your stable archive.
For Adaptive records, use `--mode adaptive` with `list` or `search`; the previous
`--mode deadline` spelling remains valid.

## Separate feedback

In Analytics, choose **Prediction mode → One-Shot**. Binary shows ordinary mean Brier
and probability calibration. Numeric shows percentile and interval calibration with
continuous-style and whole-number groups separate. Counts, uncertainty, and text tables
remain visible. Each answered Prediction counts once using its effective corrected
facts. The [Analytics guide](../../analytics-guide.md#11-one-shot-analytics) explains these
results and the limits of selectively recording exercises.

## Export and recovery

The schema is **20**. Supported v0.7 archives upgrade with their history intact;
existing v0.8 schema-19 archives gain only the nullable Saved View mode filter.
Complete SQLite backup preserves the whole supported archive and remains the recovery
format. Back up with your current compatible version before upgrading.

CSV export is now **format 5**, available from Settings and `export-csv`. It retains
the format-4 file layouts and adds One-Shot original/effective facts and full correction
snapshots. Its README explains every column, exact scaled integers, optional reported
wall times, UTC app-entry times, later-answer replay, and scoring boundaries. It includes
all four supported contracts, unresolved and Invalid history, and empty-file headers.
CSV remains analytical; it cannot restore the app and excludes Saved Views and settings.

Pre-v0.7 Binary and interval-v1 Numeric archives remain unsupported, including mixed
archives. Missing, unknown, and mismatched contracts are refused before mutation.
Reckonsolve does not convert, delete, or partially load them. Keep such originals for
a compatible earlier version.

## Scope

This remains an offline, single-user Windows source release. Private frozen builds
are validation artifacts. No installer, signing, updater, public binaries, note importer,
mobile client, synchronization, or new app artwork is included.
