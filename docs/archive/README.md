# Documentation archive

These public records preserve completed development work. They are historical context, not current implementation instructions. Current behavior lives in the [product specification](../product-spec.md), current structure in [architecture](../architecture.md), and user guidance in the [documentation index](../README.md).

## Plans and architecture history

- [Specification through v0.8](product-spec-through-v0.8.md) — the full pre-cleanup specification, including M1–M60 plans and acceptance criteria.
- [Architecture through v0.8](architecture-through-v0.8.md) — the chronological implementation account before consolidation.

Older compatibility promises and legacy editors/scoring descriptions were superseded by legacy retirement. They do not authorize conversion, deletion, partial loading, or restoration of retired runtime models. Completed plans do not authorize new implementation.
