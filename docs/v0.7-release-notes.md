# Reckonsolve v0.7.0 — source release notes

Reckonsolve v0.7 changes how forecasts are represented and scored. New Binary forecasts keep an exact, permanent Deadline and are scored over the time each probability stood, using Trajectory Brier. New Numeric forecasts use five exact quantiles (5th, 25th, median, 75th, 95th) and Weighted Interval Score. Both types retain immutable revisions, Reviews, Journals, and audited effective-resolution corrections. Analytics keeps Binary and Numeric feedback separate; [the Analytics guide](analytics-guide.md) explains how to read it.

The desktop now has a shared, initially unset Deadline picker for both forecast types. Local-calendar shortcuts target 11:59 PM; Custom entry handles daylight-saving gaps and repeated hours explicitly. The CLI continues to accept offset-bearing timestamps.

The SQLite schema is version 18. A complete SQLite backup remains the recovery format. Relational CSV export is now format 4 and includes model identities, exact Deadlines, all five quantiles, recorded and effective terminal times, and correction history with a bundled data dictionary. CSV is for analysis, not restoration. The private Windows build remains a validation artifact, not a public binary release.

**Compatibility break:** This version refuses any database or backup containing pre-v0.7 Binary or interval-v1 Numeric predictions, including mixed archives. Missing, unknown, or mismatched model identities are refused too. It does not convert, delete, or partially load those records. Keep an unsupported original or backup for an earlier compatible Reckonsolve version. Supported v0.7-only schema-16/17 Binary archives upgrade to schema 18; supported schema-18 archives reopen unchanged. Before opening an existing supported archive with the new version, make a complete SQLite backup with your current compatible version.

This is a source release. It does not include an installer, signed executable, automatic updater, importer, new forecast type, public binaries, or app logo.
